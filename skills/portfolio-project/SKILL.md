# portfolio-project: 프로젝트 자료 모으기

대상 사용자는 비개발자입니다. 한국어로, 짧게, 한 번에 질문 하나.
`portfolio` 스킬의 **공통 원칙**(지어내지 않기, 기밀·개인정보 지키기, 덮어쓰지 않기)을 그대로 따릅니다.

## 0. 위치 확인

현재 폴더에 `PORTFOLIO.md` 가 없으면 "포트폴리오 폴더가 아직 없습니다. `/portfolio` 로 폴더부터 만들까요?" 묻고, 동의하면 `portfolio` 스킬 0~1번을 먼저 합니다.

## 1. 무엇을 가져올지 묻기

1. "어떤 프로젝트를 넣을까요? 프로젝트 이름을 알려 주세요."
2. "자료는 어디 있나요?" 아래 중 무엇이든 받습니다. 여러 개 섞어도 됩니다.
   - 내 컴퓨터의 폴더나 파일 경로 (Finder/탐색기에서 폴더를 입력창으로 끌어다 놓으면 경로가 들어갑니다)
   - 붙여 넣은 텍스트 (회의 메모, 회고, 업무 일지, 자기소개서 문단)
   - 공개 링크 (블로그 글, 발표 자료, 서비스 페이지). 로그인이 필요한 페이지는 읽지 않고, 내용을 복사해 붙여 달라고 합니다.
   - 이미지 (화면 캡처, 산출물 사진)
3. 이 세션에 Notion, Google Drive 같은 연결 도구가 있으면 "Notion 페이지 주소를 주셔도 됩니다"라고 덧붙입니다. 없으면 말하지 않습니다.

## 2. 폴더 만들기

1. 이름은 `프로젝트<번호>-<짧은 이름>/` 입니다. 번호는 기존 프로젝트 폴더 다음 번호. 공백은 `-`.
2. 안에 `개요.md`(portfolio 스킬의 `templates/프로젝트-개요.md`), `자료/`, `캡처/` 를 만듭니다. `회의메모.md`, `회고.md` 는 해당 내용이 있을 때만 만듭니다.
3. 템플릿 폴더 `프로젝트1-이름바꾸기/` 가 비어 있는 채로 남아 있으면 첫 프로젝트는 그 폴더 이름을 바꿔서 씁니다.

## 3. 자료 옮기기와 거르기

1. **복사만 합니다.** 원본 위치의 파일을 옮기거나 지우지 않습니다. 문서는 `자료/`, 이미지는 `캡처/` 로 복사합니다. 폴더를 통째로 받았으면 문서·이미지 파일만 고르고, 프로그램 파일(`node_modules`, `.git`, 실행 파일)과 비밀 파일(`.env`, `*.key`, `*.pem`, `secrets*`)은 복사하지 않습니다.
2. 파일이 많으면(20개 이상) 목록을 보여주고 "이 중 프로젝트를 잘 보여주는 것만 고를까요, 전부 넣을까요?" 묻습니다.
3. 붙여 넣은 텍스트는 성격에 맞는 파일에 날짜와 함께 저장합니다: 결정·회의 → `회의메모.md`, 돌아보기 → `회고.md`, 그 밖 → `자료/메모-<날짜>.md`. 링크로 읽은 내용은 `자료/` 에 출처 URL과 함께 저장합니다.
4. 복사한 자료에서 아래를 찾아 표로 알리고 처리 방법을 묻습니다. 기본 제안은 가리기입니다(예: 고객사 실명 → "A사", 동료 실명 → "개발자 1").
   - 고객사·거래처 실명, 내부 매출·단가·계약 금액, 사내 시스템 주소·계정
   - 동료·고객의 실명, 연락처, 주민번호, 주소
   - 비밀번호, API 키, 토큰처럼 보이는 문자열 (이건 묻지 않고 바로 빼고 알립니다)

## 4. 개요 채우기

1. 모은 자료를 읽고 `개요.md` 의 칸을 채웁니다. **자료에 있는 것만** 씁니다. 각 칸은 어느 파일에서 왔는지 `출처` 목록에 적습니다.
2. 자료에 없는 칸은 비워 두지 말고 `확인 필요` 라고 씁니다.
3. 중요한 순서(내 역할 → 결과 → 판단 이유)로 최대 3개까지 질문합니다. 답은 `개요.md` 에 "(사용자 답변, YYYY-MM-DD)" 표시와 함께 적습니다. 숫자를 물을 때는 "정확하지 않으면 '대략'이라고 적어 두겠습니다"라고 말하고, 추정치를 사실처럼 바꾸지 않습니다.

## 5. 목록 갱신

1. `PORTFOLIO.md` 의 프로젝트 목록 표에 한 줄 추가합니다: 폴더 / 기간 / 확인 필요 개수 / 포트폴리오에 넣기(아직 미정이면 `미정`).
2. 끝맺음:
   > `프로젝트<번호>-<이름>` 을 만들었습니다. 자료 n개, 캡처 n장, 확인 필요 n칸.
   > 다른 프로젝트도 넣을까요? 2~3개면 충분합니다. 다 넣었으면 `/portfolio` 로 다음 단계(경험 정리)를 이어갑니다.

## 6. 목록 보기

"프로젝트 목록 보여줘" → 프로젝트 폴더마다 기간, 자료·캡처 개수, `확인 필요` 개수를 세어 표로 보여주고 `PORTFOLIO.md` 표도 같은 값으로 맞춥니다.
